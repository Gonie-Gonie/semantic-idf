Start

SemanticIDF opens EnergyPlus IDF, IMF, and epJSON-style files, shows the input in synchronized Text, JSON, and Table views, and calculates Metrics, Topology, Profile, HVAC, and Simulation results in the right panel. A reference office model loads at startup so the interface is usable before you open a project file; analysis starts after the first screen is visible and fills in the visible Metrics first.

Files

Open

Loads `.idf`, `.imf`, `.epjson`, `.json`, or `.txt` from the desktop file picker and analyzes it automatically.

Save

Writes the current editor text back to the opened file. If there is no original file path, the app asks where to save.

Revert

Restores the input text to the snapshot from the most recent open operation.

Automatic Analysis

Analysis runs after opening a file, and structured input edits refresh the document without a separate Analyze button.

CLI Commands

The packaged executable can also run non-interactive commands. Running without arguments opens the desktop app; running `semantic-idf cli ...` or a recognized top-level command runs the CLI. Use `-` as the input path to read from stdin and `-o -` to write command output to stdout.

Metrics and diagnostics

Export text, JSON, CSV, or styled XLSX metrics, and export diagnostic issues for scripts or CI checks.

semantic-idf cli metrics model.idf
semantic-idf cli metrics -format json -o metrics.json model.idf
semantic-idf cli metrics -format csv -o metrics.csv model.idf
semantic-idf cli metrics -format xlsx -o metrics.xlsx model.idf
semantic-idf cli diagnostics -format text model.idf
semantic-idf cli diagnostics -format csv -o diagnostics.csv model.idf
semantic-idf cli analyze -format json -o report.json model.idf

Batch metrics

Compare metrics across several models as CSV, JSON, text, or a styled XLSX workbook.

semantic-idf cli batch-metrics -format csv -o compare.csv a.idf b.idf c.epjson
semantic-idf cli batch-metrics -format xlsx -orientation metrics -o compare.xlsx a.idf b.idf
semantic-idf cli batch-metrics -format xlsx -orientation files -o compare-by-file.xlsx a.idf b.idf

Clean

Preview cleanup candidates, apply default or explicit rules, compact formatting, and optionally rename duplicate semantic object names.

semantic-idf cli clean --dry-run model.idf
semantic-idf cli clean --dry-run -format json -o cleanup-preview.json model.idf
semantic-idf cli clean -o cleaned.idf model.idf
semantic-idf cli clean -rules all --compact -o cleaned.idf model.idf
semantic-idf cli clean -rules none --semantic-duplicates -o semantic-fixed.idf model.idf
semantic-idf cli clean -rules remove_unused_schedules,remove_duplicate_output_variables -o cleaned.idf model.idf

Convert

Convert IDF and epJSON inputs to IDF, epJSON, semantic YAML view export, or a styled one-sheet Excel table export grouped by `[ObjectType]` markers.

semantic-idf cli convert -to idf -o model.idf model.epjson
semantic-idf cli convert -to json -o model.epjson model.idf
semantic-idf cli convert -to yaml -o model.semantic.yaml model.idf
semantic-idf cli convert -to table -o model.tables.xlsx model.idf
type model.idf | semantic-idf cli convert -to json -o - -

Input Views

Text

Shows the full input as editable object and field summaries. Changes update the saved source document directly.

JSON

Shows an epJSON-shaped structured view. Value tokens can be edited inline while syntax tokens remain read-only.

Table

Shows object-type tables with switchable row and column orientation for scanning fields across similar objects.

Filter

The left-panel filter works the same way across Text, JSON, and Table views by matching object type, object name, field label, and value text.

Metrics

Metrics groups model inventory, area, envelope, load, schedule, and HVAC values. Export JSON keeps the grouped structure, while Export CSV creates `name,value` rows. CSV names use variable-style names with units in brackets, including `[-]` for values without a physical unit.

Spatial & Thermal Topology

Topology shows parsed zones, surfaces, and fenestration in 3D and plan views. Selecting an item shows key metrics and related objects such as parent zones, base surfaces, child windows, adjacent zones, and matching surfaces. Selecting an object automatically links to its matching input object.

Batch Metrics

Batch Metrics is available from Tools. Select it from the left selector, then choose several input files, wait for the progress bar to finish, then review the combined metrics table. Metrics can be shown as rows with buildings as columns, or transposed with buildings as rows. Export CSV uses the currently selected table direction.

Tools / Diagnose

Cleanup suggestions are available from Tools / Diagnose and use the current app input snapshot or a separately selected input. Choose rules on the left, then review filterable candidate checkboxes on the right to include or exclude individual removals. Apply selected updates the editor and re-runs analysis, while Save cleaned copy writes a new file. Current rules cover unused schedules, unused envelope resources, unused curves/tables, duplicate Output objects, and compact formatting. Comment-only cleanup is reserved for later.

Settings

Settings opens as its own page. Appearance controls choose the app theme and Topology colors for zones, walls, roofs, windows, selections, and the 3D background.
